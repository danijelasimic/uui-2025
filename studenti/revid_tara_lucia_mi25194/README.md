# Lična web prezentacija

Ovaj projekat predstavlja jednostavnu web prezentaciju izrađenu korišćenjem HTML-a i CSS-a.

## Sadržaj projekta

Projekat sadrži tri međusobno povezane HTML stranice:

- `index.html` – početna stranica
- `o_meni.html` – stranica sa osnovnim informacijama o autoru
- `tema.html` – stranica o veštačkoj inteligenciji i umetnosti

Za izgled svih stranica koristi se zajednički CSS fajl:

- `style.css`

Projekat sadrži i LaTeX dokument:

- `main.tex`

Iz njega je generisan PDF dokument:

- `rad.pdf`

Sve slike koje se koriste u projektu nalaze se u folderu:

- `slike/`

## Tema

Tema web prezentacije je veštačka inteligencija u umetnosti i njena primena u kreativnom radu.
