Istorija Pythona

Python je nastao krajem osamdesetih godina 20. veka kao naslednik jezika ABC, koji je Guido van Rossum razvijao u istraživačkom centru CWI u Holandiji.

Prva javna verzija, Python 0.9.0, objavljena je 1991. godine. Ime je dobio po čuvenoj britanskoj humorističkoj seriji Monty Python's Flying Circus, a ne po zmiji, kako mnogi pogrešno misle.

Hronologija razvoja

Verzija Godina Ključna novina
0.9.0 1991. Prvo javno izdanje
2.0 2000. Liste razumevanja, Unicode podrška
3.0 2008. Prekid kompatibilnosti sa Python 2
3.10 2021. Strukturno poklapanje (match/case)
3.12 2023. Brži interpreter, bolje poruke o greškama

Python 2 vs Python 3

Prelazak sa Python 2 na Python 3 bio je jedan od najvećih izazova u istoriji jezika. Iako je Python 3 objavljen još 2008. godine, tek 2020. godine Python 2 je zvanično prestao da se podržava.

Glavne razlike:

  • print je funkcija u Python 3 (u Python 2 je bio naredba)
  • Stringovi su podrazumevano Unicode u Python 3
  • Deljenje celih brojeva vraća decimalni rezultat u Python 3
  • Bolja podrška za asinhrone operacije

Zanimljivosti

  1. Python je nazvan po komičarskoj grupi Monty Python.
  2. Guido van Rossum je bio "Benevolent Dictator For Life" (BDFL) do 2018. godine.
  3. Python je jedan od retkih jezika koji se koristi i u osnovnim školama i u NASA-i.
