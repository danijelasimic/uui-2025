\section{Увод}

\textbf{Python} је програмски језик високог нивоа, опште намене, који је
створио \textit{Гвидо ван Росум} крајем осамдесетих година 20. века.
Његова основна филозофија је \textcolor{zelena}{једноставност, читљивост и
продуктивност}. Данас се користи у веома широком спектру области — од
веб развоја, преко науке о подацима, до вештачке интелигенције.

Један од најпознатијих примера једноставности језика је чувена
формула еквиваленције масе и енергије, која се у физици записује као
$E = mc^2$, а у Python-у би се израчунала у једној линији:

\begin{center}
\texttt{energija = masa * brzina\_svetlosti ** 2}
\end{center}

\subsection{Филозофија језика}

Основна начела Python-а описана су у документу \textit{The Zen of Python}:

\begin{itemize}
    \item \textit{Лепо је боље од ружног.}
    \item \textit{Јасно је боље од нејасног.}
    \item \textit{Једноставно је боље од сложеног.}
\end{itemize}

Поред тога, постоје и практични савети:

\begin{enumerate}
    \item Користити увлачење од четири размака.
    \item Писати читљив код.
    \item Документовати функције.
\end{enumerate}

\section{Примена}

\subsection{Области примене}

Python се данас примењује у следећим областима:

\begin{itemize}
    \item \textbf{Веб развој} (Django, Flask, FastAPI)
    \item \textbf{Наука о подацима} (NumPy, Pandas, Matplotlib)
    \item \textbf{Вештачка интелигенција} (TensorFlow, PyTorch)
    \item \textbf{Аутоматизација} скрипти и задатака
    \item \textbf{Образовање} — као уводни језик у програмирање
\end{itemize}

\section{Теоријски оквир}

У овом одељку наведени су основни математички и логички појмови
релевантни за анализу алгоритама.

\begin{definicija}
\textbf{Алгоритам} је коначан низ јасно дефинисаних корака који доводе
до решења неког проблема.
\end{definicija}

\begin{teorema}[о сложености]
Ако алгоритам има сложеност $O(n \log n)$, тада је бржи од алгоритма
сложености $O(n^2)$ за довољно велико $n$.
\end{teorema}

\begin{proof}
Следи директно из особина логаритамске функције и дефиниције
асимптотске сложености.
\end{proof}

\begin{lema}
Сваки проблем који се може решити у полиномијалном времену припада
класи $P$.
\end{lema}

\section{Закључак}

Python представља један од најзначајнијих програмских језика данашњице.
Његова једноставност, читљивост и огромна библиотека чине га идеалним
избором како за почетнике, тако и за искусне програмере. Од свог
настанка 1991. године до данас, Python је прошао дуг пут и постао
незаобилазан алат у науци, индустрији и образовању.
