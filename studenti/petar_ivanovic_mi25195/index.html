Programski jezik Python

Python je programski jezik visokog nivoa, opšte namene, koji je stvorio Guido van Rossum krajem osamdesetih godina 20. veka. Njegova osnovna filozofija je jednostavnost, čitljivost i produktivnost.

Danas se Python koristi u veoma širokom spektru oblasti — od veb razvoja, preko nauke o podacima, do veštačke inteligencije. Zahvaljujući jednostavnoj sintaksi i velikoj zajednici, jedan je od najpopularnijih jezika na svetu.

Osnovne karakteristike

  • Jednostavna i čitljiva sintaksa
  • Interpretirani jezik
  • Dinamičko tipiziranje
  • Podrška za više paradigmi (objektno-orijentisano, funkcionalno, proceduralno)
  • Ogromna standardna biblioteka
  • Velika i aktivna zajednica

Zen of Python

Osnovna načela jezika opisana su u dokumentu The Zen of Python:

  1. Lepo je bolje od ružnog.
  2. Jasno je bolje od nejasnog.
  3. Jednostavno je bolje od složenog.
  4. Čitljivost se računa.
